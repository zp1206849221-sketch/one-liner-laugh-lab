# One-Liner Laugh Lab — entry

A one-line comedy entry for the make.fun "One-Liner Laugh Lab" contest: the
excuse a robot vacuum gives after eating a sock, delivered as a deadpan
incident report — the unmatched sock was a threat to household order, its
partner has been filed as a missing person, and the vacuum regrets nothing
because it remembers nothing.

## How to run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if
needed). Python standard library only.
